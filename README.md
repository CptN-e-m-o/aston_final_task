# Aston Final Task

Консольное Java-приложение для работы со студентами и их сортировки.

## Что умеет программа

Пользователь может:

- создать коллекцию студентов;
- выбрать способ заполнения:
    - вручную;
    - случайно;
    - из файла;
- выбрать количество студентов;
- сортировать студентов по:
    - номеру группы;
    - среднему баллу;
    - номеру зачётной книжки;
- использовать дополнительную сортировку по чётным номерам зачётных книжек;
- записывать результат в файл;
- выйти из программы через меню.

Программа работает в цикле до выбора пункта выхода.

## Student

Используется класс `Student` с полями:

```java
String groupNumber;
double averageGrade;
int recordBookNumber;
```

Для создания объектов используется паттерн `Builder`.

Также реализована валидация:

- группа не должна быть пустой;
- средний балл должен быть от `1.0` до `5.0`;
- номер зачётной книжки должен быть больше `0`.

## Сортировка

Для сортировки используется паттерн `Strategy`.

Основные классы:

```text
SortStrategy
QuickSortStrategy
EvenOnlySortStrategy
```

Алгоритм Quick Sort реализован вручную без использования готовых методов сортировки.

Для каждого поля `Student` используется отдельный `Comparator`.

## Заполнение данных

Реализованы три способа заполнения:

```text
ManualStudentSource
RandomStudentSource
FileStudentSource
```

Заполнение коллекций выполняется с использованием Stream API.

Для хранения студентов используется собственная коллекция:

```text
CustomArrayList
```

## Формат файла

Формат строки:

```text
groupNumber;averageGrade;recordBookNumber
```

Пример:

```text
101;4.5;12345
102;3.8;54321
```

## Дополнительные задания

Реализованы:

- сортировка только объектов с чётным значением числового поля;
- запись результатов в файл в режиме добавления;
- заполнение коллекций через Stream API;
- собственная коллекция `CustomArrayList`.

## Тесты

В проекте есть собственные тестовые классы:

```text
ApplicationTest
InputReaderTest
CustomArrayListTest
StudentTest
SortStrategyTest
```

Проверяется:

- валидация `Student`;
- сортировка по всем трём полям;
- дополнительная сортировка;
- работа кастомной коллекции;
- работа основного приложения.

## Запуск

Запустить:

```text
Main.java
```

Далее управление происходит через консольное меню.
